## Tarot images

The 22 Rider–Waite–Smith major arcana images are stored locally in `assets/tarot/` for reliable loading. Source: [mixvlad/TarotCards](https://github.com/mixvlad/TarotCards), `tarot/rider-waite/720px/`. The repository identifies the Rider–Waite images as public domain; the original deck was illustrated by Pamela Colman Smith and published in 1909.
